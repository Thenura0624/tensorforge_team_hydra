# Saved model-comparison evidence

These reports are copied from the completed model-tournament experiments. They support the repository README charts and tables. Candidate primary scores use the same 600-ticket internal comparison set, after candidate refitting on 3,400 rows.

Original reports retain their recorded run paths for provenance. Those paths are machine-specific and are not deployment instructions. Large neural weights, prediction arrays and complete training histories are not included here. Re-run the training/comparison workflow to generate fresh portable run outputs.

The selected candidate is XLM-R. Final full-data XLM-R training and supplied-validation results were not present in the reviewed source artifacts. Baseline validation metrics live one directory above, in metrics.json, and use a different 800-ticket population.
